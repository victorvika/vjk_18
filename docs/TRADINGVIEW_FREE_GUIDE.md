# TradingView Free Plan la LSMS v4 Use Pandradhu Eppdi? (No Subscription)

Pay panna thevai illa. Free (Basic) plan-laye Pine Editor use panni LSMS v4-a chart-la podalam.
**Save aagalanu kavala padadha — code unga GitHub repo-la safe-a iruku** (`indicators/LSMS_v4_Pro.pine`),
so ovvoru session-um anga irundhu copy-paste panna 1 minute dhaan aagum.

---

## Method 1 (Recommended): Save pannama "Add to chart" mattum

1. **Desktop browser** (Chrome/Edge) la po — mobile app-la Pine Editor full support kedayaadhu.
2. [tradingview.com](https://www.tradingview.com) → **Sign in** → free account (email/Google).
   Login pannama irundha dhaan Save/Add pannum bodhu subscription popup varum — adhu dhaan #1 reason.
3. Chart open pannu → symbol **EURUSD**, timeframe **5m** (illa 15m).
4. Chart mela vera indicators irundha remove pannu (free plan = max **2 indicators/chart**; LSMS onney podhum).
5. Bottom-la **Pine Editor** tab click pannu (illa `Ctrl+Shift+P`).
6. Pine Editor-la **Open → New blank indicator** select pannu.
7. Editor-la already iruka code ellame select panni (`Ctrl+A`) delete pannu.
8. Repo-la iruka [`indicators/LSMS_v4_Pro.pine`](../indicators/LSMS_v4_Pro.pine) file-a open panni, full code copy-paste pannu.
9. **Save click pannadha!** Adhuku badhilaa editor top-right-la **"Add to chart"** click pannu.
10. Script compile aagi chart-la apply aagum. Dashboard top-right-la varudha-nu check pannu,
    left-top-la `LSMS v4 Pro` nu name theriyum.

Avlodhaan — subscription thevaiye illa. Tab refresh aana script pogalam; appo Step 8 repeat pannu (1 min velai).

## Save pannanum-na (private script, free)

- Editor-la irundhukite `Ctrl+S` (illa top-la disk/save icon) → name kodu (`LSMS v4 Pro`) → **Save**.
- Free account-la **private script save pandradhu free dhaan.**

> ⚠️ **"Publish script" click pannadha!** Save vera, Publish vera.
> Publish = community-ku public release — adhula dhaan subscription/verification ketkum.
> Popup vandha neenga wrong button-a click panni irupeenga.

## Subscription popup vandha — reason & fix

| Enga click pannum bodhu varudhu? | Reason | Fix |
|---|---|---|
| Pine Editor **Save** | Login pannala / guest session | Sign out → free account-la Sign in panni retry |
| **Publish script** | Idhu public release, private save illa | Publish venaam, `Ctrl+S` use pannu |
| Chart top-la **Save (layout)** | Free = 1 saved layout; pazhaya layout iruku | Pazhaya layout-a delete panni, illa adhulaye overwrite pannu |
| **Add to chart** | Chart-la already 2 indicators iruku | Pazhaya indicators remove pannitu LSMS podum |
| Alert create pannum bodhu | Free-la technical alerts limited/paid | Alerts skip pannu; visual-a dashboard paatha podhum (paid vendam) |
| Script run aagama "calculation timeout" | Free-la script runtime limit korava | 5m/15m use pannu; settings-la HTF zones/showPD zones off panni paar |

## Daily use-ku tips

- Chart-la **LSMS v4 Pro mattum** vechuko (free 2-slot limit save aagum).
- Alerts free-la nambadha — **Bar Replay / live chart dashboard** vechi practice pannu.
- Pazhaya session code venum-na GitHub repo dhaan unmaiyaana backup. TradingView save-aiye nambi iruka thevai illa.
- Settings first time: ella default; `Confluence Score → Min Score 70`; symbol EURUSD/GBPUSD; 5m/15m.
