## Honest gaps in the source

The video is a tour, not a project build. It does not cover:

- Multicam editing (CapCut Desktop has no true multicam; sync manually and cut between tracks)
- Colour management / HDR delivery beyond the basics
- Team collaboration and shared draft folders
- Advanced audio mixing (EQ, compression, sidechain) - CapCut's toolset is shallow here

If the user needs those, say so plainly and route them to DaVinci Resolve (colour, audio) or
Premiere Pro (multicam) rather than pretending CapCut covers it.
