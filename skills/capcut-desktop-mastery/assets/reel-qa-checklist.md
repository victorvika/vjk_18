# Pre-export QA checklist

Run this every time. It takes 4 minutes and catches 90 % of "why did this get rejected" moments.

## A. Story and pacing (watch once, start to finish)

- [ ] First 1.5 seconds contain motion, a face, a bold claim, or a visual surprise - not a logo
- [ ] The hook is understandable **without audio**
- [ ] There is exactly one idea in the video, not three
- [ ] No shot overstays its usefulness; no shot is too short to read
- [ ] The ending resolves: CTA, punchline, or loop back to the first frame
- [ ] Loop test: does the last frame flow back into the first? (for Reels/Shorts)

## B. Cuts and motion

- [ ] No black frames, frozen frames, or 0.1 s flashes of a wrong clip
- [ ] Every cut lands on a word or a beat - not mid-breath
- [ ] J-cuts / L-cuts used at least twice (audio leads or trails the picture)
- [ ] Camera moves are eased, not linear
- [ ] Zoom/punch-ins are intentional, not accidental

## C. Audio (watch once at 2× and once on a phone speaker)

- [ ] Dialogue is clear over the music at normal phone volume
- [ ] Music ducks under every sentence
- [ ] No clipping (no red peaks), no distortion
- [ ] No abrupt starts/stops: every track faded
- [ ] Breaths selectively removed, room tone preserved
- [ ] SFX are felt, not noticed
- [ ] Sync holds at the start, middle, and end

## D. Text and captions

- [ ] Every caption checked against the audio, word by word (names, numbers, brands)
- [ ] No caption in the bottom 25 % or right 15 % of a 9:16 frame
- [ ] Maximum two lines per caption
- [ ] One font family, two weights maximum
- [ ] Tamil glyphs render correctly (no boxes, no clipped vowel signs)
- [ ] No keyword highlighted in a colour that disappears on the background
- [ ] Hook text stays long enough to read twice

## E. Colour and image

- [ ] Shots match each other (no one clip warmer/darker than its neighbours)
- [ ] Skin tones look like skin, not orange or grey
- [ ] No crushed blacks or blown highlights unless deliberate
- [ ] Checked on a phone, not only the editing monitor
- [ ] LUT intensity consistent across the video

## F. Technical

- [ ] Canvas matches the delivery target
- [ ] Frame rate matches the source footage
- [ ] No media offline warnings in the project
- [ ] Export bitrate appropriate to the platform
- [ ] Export plays in a browser, on a phone, and in WhatsApp
- [ ] File size acceptable for the delivery channel

## G. Delivery

- [ ] Filename: `YYYYMMDD_client_topic_platform_vNN.mp4`
- [ ] Exported to the project's `exports/` folder
- [ ] Cover/thumbnail exported
- [ ] Music + font licence notes attached
- [ ] Review copy sent at `Recommended` bitrate, final at `Higher`
- [ ] Draft folder + footage archived with matching names

## Sign-off

| Check | By | Date |
|---|---|---|
| Story / pacing | | |
| Audio | | |
| Text | | |
| Technical export | | |

Only the last row needs to be true before the file leaves the machine.
